The GraphQL route accepts only seven generated operations, such as [GetEndpoint](../../graphql/operations/query/endpoint/). Generic `Execute`, `Query`, and `Mutate` reject other documents. The directive stream has an [AsyncAPI reference](../../asyncapi/event-stream/receiveDirectives/). Metric event properties and behavior sequence nodes are generated from [`api/embedded-wire.yaml`](https://github.com/portpowered/go-alexa/blob/main/api/embedded-wire.yaml); `RunBehavior` checks its input against those node types before sending. Feature and operation path values, and some operation payload fields, remain caller supplied as the schemas specify.
