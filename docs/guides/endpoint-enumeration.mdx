---
title: 'Enumerate endpoints'
---

`Session.ListEndpoints` combines GraphQL endpoint data with optional REST device metadata. Set `Properties` to request state values and `Features` to request supported feature metadata.

```go
response, err := session.ListEndpoints(ctx, alexaapimodels.EndpointQuery{
    IncludeFields: &alexaapimodels.EndpointIncludeFields{
        Properties: true,
        Features:   true,
    },
})
if err != nil {
    return err
}
for _, endpoint := range response.Results {
    name := endpoint.EndpointID
    if endpoint.FriendlyName != nil {
        name = endpoint.FriendlyName.Value
    }
    fmt.Printf("%s: %s (%d features)\n", name, endpoint.EndpointID, len(endpoint.Features))
}
```

If the secondary REST request fails, the result may omit REST-only fields. Feature names describe reported capabilities; they do not guarantee a command will succeed on a device.

Set `EndpointIDs` to the exact vendor identifiers you previously discovered to
scope a state read. With `Properties: true`, selected reads use GraphQL directly
and do not fetch account-wide REST device metadata. Results exclude unrelated
provider identities, and supplement missing air-quality sensor properties only
for the selected identities. Discovery remains responsible for physical device
and owner context. Unavailable properties remain distinct from measured zero.
