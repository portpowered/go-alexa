Use these guides with the public `pkg/alexa` client and an account session.

- [Authentication](./authentication/) covers credentials and token exchange.
- [Client configuration](./client-configuration/) supplies HTTP and HTTP/2 transports.
- [Command line](./cli/) links an account and runs common endpoint workflows.
- [Endpoint enumeration](./endpoint-enumeration/) finds devices and features.
- [Endpoint control](./endpoint-control/) sends feature operations.
- [Events](./events/) opens and closes a directive stream.
- [Quality of service](./quality-of-service/) requests an endpoint policy.
- [Player state](./player-state/) reads playback status for a device.
- [Upgrading](./upgrading/) explains changes for callers using v0.3.

The [code-pair reference](../openapi/account-linking/createCodePair/) is an entry point to the generated HTTP pages. Examples use synthetic values.
