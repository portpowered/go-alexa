Use these guides with the public `pkg/alexa` client and an account session.

- [Authentication](./authentication/) covers credentials and token exchange.
- [Endpoint enumeration](./endpoint-enumeration/) finds devices and features.
- [Endpoint control](./endpoint-control/) sends feature operations.
- [Events](./events/) opens and closes a directive stream.
- [Wire contracts](./wire-contracts/) lists the generated HTTP operations and embedded schemas.
- [Quality of service](./quality-of-service/) requests an endpoint policy.

The [code-pair reference](../openapi/account-linking/createCodePair/) is an entry point to the generated HTTP pages. The guides use synthetic examples; the maintainer's account tests were not recorded with sanitized exchanges.
